# Glossary for Biologists Entering Computational Biology

### API
Application Programming Interface; allows programs to communicate and use each other’s functions.

### Algorithm
A step-by-step procedure for solving a problem or performing a task.

### Argument
A value passed to a [function](https://github.com/sdhutchins/computational-biology-starter-kit/blob/main/glossary.md#function) when it is called.

### Assertion
A statement in code used to check that a condition is true at a specific point. If false, it halts execution.

### Assertions
Statements that check conditions during execution, halting if false.

### Automation
The use of scripts or tools to perform repetitive tasks automatically, improving reliability and efficiency.

### Bug
An error in a program that causes incorrect or unexpected results.

### CLI
Command Line Interface; a way to interact with software via typed commands.

### CSV
Comma-Separated Values, a file format used to store tabular data.

### Code Review
A process where others examine code changes to ensure quality and correctness.

### Collaboration
Working with others through shared tools like Git, issue trackers, and code reviews.

### Command Line Interface (CLI)
A way to interact with software via typed commands rather than a graphical interface.

### Commit
A recorded change in a version control system.

### Container
A lightweight, reproducible computing environment (e.g., Docker) that encapsulates code and dependencies.

### Containerization
Packaging applications and environments for portability and reproducibility.

### DRY (Don't Repeat Yourself)
A principle encouraging code reuse to avoid duplication.

### Data Frame
A table-like data structure in R and Python used for statistical and data analysis.

### Data Pipeline
A series of automated data processing steps.

### Debugger
A tool for pausing and inspecting a program to diagnose and fix errors.

### Dependency
A software library or package required for a program to run.

### Docstring
A special string at the beginning of a function or module that describes what it does.

### Environment
The combination of OS, packages, and configuration under which code is executed.

### Function
A reusable block of code that performs a specific task.

### Git
A version control system for tracking changes in source code.

### IDE
Integrated Development Environment; software that provides tools to write and debug code.

### Import
The act of loading a library or module into a script.

### Interactive Shell
A command-line tool that executes code in real-time (e.g., Python REPL).

### Issue Tracker
A tool to track bugs, tasks, and feature requests.

### Jupyter Notebook
An interactive computing environment often used for data analysis and visualization.

### Library
A collection of pre-written code that can be reused in programs.

### Logging
Recording information during program execution to aid debugging and monitoring.

### Loop
A programming construct used to repeat a block of code.

### Makefile
A file containing commands to automate build processes.

### Markdown
A lightweight markup language for formatting plain text.

### Modularity
The design principle of building software in independent, interchangeable units.

### Notebook
An interactive document combining code, results, and narrative.

### Open Source
Software with source code freely available for use, modification, and distribution.

### Package
A collection of modules or functions bundled for distribution.

### Pipeline
A structured series of steps to process data.

### Plot
A visual representation of data.

### Profiler
A tool that measures how much time or memory code consumes.

### Pull Request
A request to merge code changes into a shared repository.

### README
A file that describes a project’s purpose, setup, and usage.

### Random Seed
A number used to initialize a pseudorandom number generator to ensure reproducibility.

### Refactor
To restructure code without changing its behavior to improve readability or performance.

### Reproducibility
The ability to rerun an analysis and obtain the same results.

### Script
A file of code that executes a series of commands.

### Shell
A command-line interpreter that executes user commands.

### Snakemake
A workflow management system that automates reproducible pipelines.

### Source Code
Human-readable code written in a programming language.

### Symbolic Debugger
A debugger that lets you inspect variables and the call stack in real-time.

### Test Case
Code written to ensure a specific function or feature works correctly.

### Unit Test
A test for a small part of a program, such as a single function.

### Variable
A symbolic name associated with a value.

### Version Control
A system that records changes to files over time (e.g., Git).

### Virtual Environment
A self-contained directory that contains a Python installation and packages.

### Workflow
A set of processes or tasks structured to complete a data analysis.

### YAML
A human-readable data serialization standard often used for configuration.
